# Produção VIP — Cloudflare Pages

Este repositório é um site estático pronto para Cloudflare Pages.

## Estrutura

- index.html — Central de Produção
- acompanhamento.html — acompanhamento público
- setores.html — setores e extensões
- links.html — links de produção
- _headers — cabeçalhos de segurança/cache
- _redirects — rotas amigáveis

## Configuração

Framework preset: None
Build command: vazio
Build output directory: / (raiz do repositório)

O site usa a API Supabase da Produção VIP para os dados online.
